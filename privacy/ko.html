HairZen 개인정보 안내

시행일: 2026년 11월 13일

HairZen은 개인용 AI 헤어스타일 어시스턴트입니다. 기기에서 처리할 수 있는 것은 기기를 떠나지 않는다는 원칙으로 설계되었습니다. 이 안내에는 기기에만 남는 데이터, 사용자가 직접 요청할 때만 전송되는 데이터, 처리 방식, 행사할 수 있는 권리가 담겨 있습니다.

1. 기기 안에서만 이루어지는 처리

  • 얼굴 감지 및 사진 분석: 카메라 체험·헤어 진단의 얼굴형 분석은 Apple Vision 프레임워크로 기기 안에서 처리되며, 이 과정에서 사진은 전송되지 않습니다.
  • 렌더링 기록: 생성한 결과는 기기에만 저장되고 계정별로 분리되며, 자동 업로드나 동기화가 이루어지지 않습니다.

2. 사용자가 직접 요청할 때만 일어나는 일

직접 “생성” 버튼을 눌렀을 때만(AI 체험·3D 모델·회전 영상) 선택한 사진이 결과 생성을 위해 서버로 전송됩니다:

  • 사진은 요청한 효과를 만드는 데만 사용되며 광고나 모델 학습에는 사용되지 않습니다;
  • 서버는 원본과 결과물을 장기 보관하지 않습니다: 렌더링 완료 후 임시 데이터는 단기간 내 자동 삭제됩니다;
  • 렌더링 중 사진은 위탁된 AI 생성 서비스 제공사(이미지·3D·영상)에만 전달되며, 처리는 요청한 결과 생성으로 제한됩니다.

3. 그 외 수집 정보

  • 계정 식별자: 로그인 후 필요 최소한의 식별자(예: Apple 로그인 ID)만 저장합니다. 이름·전화번호는 수집하지 않습니다.
  • 기기·네트워크 정보: 무료 체험 남용 방지를 위해 기기 증명서와 IP 주소를 요청 제한 및 중복 수령 감지에 사용합니다. 로그의 식별자는 마스킹됩니다.
  • 크레딧과 주문: 잔액, 사용 내역, 구매 기록(대사 및 환불용).

4. 제3자 서비스

  • Apple: 인앱 결제, 로그인, DeviceCheck.
  • 위탁 AI 생성 서비스: 사용자가 능동적으로 렌더링할 때만 사진을 전달받습니다.
  • WeChat: 위챗 로그인과 위챗 결제는 미니프로그램 버전에서만 사용되며, iOS 앱에서는 사용하지 않습니다.

5. 보존 기간 및 삭제

  • 앱 삭제 또는 기록 삭제 시 기기 안의 로컬 데이터는 모두 삭제됩니다;
  • 계정 탈퇴 후 서버 측 계정 데이터는 삭제 또는 가명 처리됩니다;
  • 업로드된 사진과 생성 결과는 임시 처리만 되며 장기 보관되지 않습니다.

6. 아동 개인정보

본 앱은 아동을 위한 서비스가 아니며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 보호자 동의 없이 아동이 정보를 제공한 경우 연락 주시면 확인 후 삭제하겠습니다.

7. 사용자의 권리

당사는 사용자의 개인정보를 판매하지 않습니다. GDPR, CCPA 등 관련 법령에 따라 열람·정정·삭제·처리 제한·동의 철회 권리(서버 데이터를 지우는 계정 삭제 포함)를 행사할 수 있습니다. ayningai@outlook.com으로 연락해 주세요.

8. 보안

모든 통신은 HTTPS로 암호화됩니다. 로그에는 전체 얼굴 이미지, 완전한 기기 식별자, 원본 IP 주소를 기록하지 않습니다. 접근 키는 서버에만 보관됩니다.

9. 안내의 변경

처리 방식에 중대한 변경이 있을 경우 본 페이지와 시행일을 갱신합니다. 변경 후 계속 사용하면 갱신된 안내에 동의한 것으로 간주됩니다.
